# data/

Seed data statici per il Central Core.

## veneto-territory-seed.json

Dataset territoriale Veneto basato su fasce OMI (Agenzia delle Entrate, 2023-2024).
Usato come contesto base per radar territoriale e brief agenzia quando Apify non ha dati freschi.

Fonte prezzi: OMI — fasce orientative, non prezzi di mercato reale.
Dati mancanti: volumi annunci, NTN per comune, microzone GIS dettagliate.
